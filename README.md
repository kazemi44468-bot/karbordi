# کاربُردی | انتقال فایل بین ویندوز و اندروید

ابزار ساده انتقال فایل در شبکه محلی بین دو رایانه Windows 11 و گوشی Android. یک رایانه ویندوزی میزبان می‌شود و بقیه دستگاه‌ها با مرورگر به آن متصل می‌شوند؛ نیازی به حساب کاربری، فضای ابری یا نصب برنامه روی گوشی نیست.

## شروع سریع

1. روی رایانه میزبان Python 3.10 یا جدیدتر را از https://www.python.org/downloads/windows/ نصب کنید و هنگام نصب گزینه **Add Python to PATH** را فعال کنید.
2. فایل‌های مخزن را دانلود و از حالت فشرده خارج کنید.
3. روی `start.bat` دوبار کلیک کنید.
4. آدرس و کد اتصال نمایش‌داده‌شده در پنجره را نگه دارید.
5. گوشی و رایانه دیگر را به همان شبکه Wi-Fi وصل کنید و آدرس را در مرورگرشان باز کنید.
6. کد اتصال را وارد کنید. فایل‌ها را بارگذاری یا از فهرست دریافت کنید.

## پوشه‌ها

- `KarbordiFiles/Shared`: فایل‌هایی که می‌خواهید سایر دستگاه‌ها دریافت کنند.
- `KarbordiFiles/Received`: فایل‌هایی که از دستگاه‌های دیگر می‌فرستید.

پوشه‌ها کنار فایل برنامه ساخته می‌شوند. برای ارسال فایل از ویندوز، آن را داخل `Shared` کپی کنید و صفحه را تازه‌سازی کنید.

## نکات مهم

- نسخه اول برای شبکه محلی طراحی شده است؛ انتقال از طریق اینترنت یا خارج از شبکه محلی ارائه نمی‌شود.
- رایانه میزبان باید روشن بماند و پنجره برنامه باز باشد.
- اگر Windows Firewall پرسید، فقط برای شبکه خصوصی (Private network) اجازه دسترسی بدهید.
- کد اتصال را فقط با افراد مورداعتماد در شبکه خود به اشتراک بگذارید.
- فایل‌ها روی رایانه میزبان ذخیره می‌شوند؛ این ابزار سرویس ابری نیست.
- برای توقف سرویس، در پنجره برنامه `Ctrl+C` را بزنید.

## عیب‌یابی

- مطمئن شوید هر سه دستگاه به یک Wi-Fi متصل‌اند و شبکه از قابلیت **Client/AP isolation** استفاده نمی‌کند.
- اگر صفحه باز نشد، اجازه دسترسی Python را در Windows Firewall برای شبکه خصوصی بدهید.
- اگر دستور Python شناخته نشد، Python را نصب کنید و دوباره `start.bat` را اجرا کنید.

## حریم خصوصی

سرور روی شبکه محلی اجرا می‌شود و به سرویس ابری متصل نیست. بااین‌حال، هر دستگاهی که به شبکه دسترسی داشته باشد می‌تواند تلاش کند به سرویس وصل شود؛ کد اتصال را محرمانه نگه دارید و از شبکه عمومی استفاده نکنید.
