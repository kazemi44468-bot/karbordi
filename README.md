# کاربُردی | انتقال فایل بین ویندوز و اندروید

**یک ابزار ساده با صفحه فارسی و تم سبز و سفید** برای جابه‌جایی فایل بین دو رایانه Windows 11 و گوشی Android در یک شبکه Wi-Fi. روی گوشی نیازی به نصب برنامه نیست؛ از مرورگر استفاده می‌کنید.

## نسخه برنامه ویندوزی (پیشنهادی)\n\nمخزن به ساخت فایل اجرایی مستقل ویندوز نیز مجهز شده است. پس از پایان ساخت خودکار، وارد بخش [Actions مخزن](https://github.com/kazemi44468-bot/karbordi/actions/workflows/build-windows.yml) شو، آخرین اجرای **Build Windows app** را باز کن و از پایین صفحه در بخش **Artifacts** فایل **Karbordi-Windows** را دانلود و استخراج کن. سپس روی `Karbordi.exe` دوبار کلیک کن. این نسخه به نصب جداگانه Python نیاز ندارد.\n\nپنجره برنامه، آدرس‌ها و کد اتصال را نشان می‌دهد و دکمه‌ای برای باز کردن صفحه انتقال دارد. گوشی و رایانه دوم باید به همان Wi-Fi وصل باشند.\n\n## راه‌اندازی نسخه کد منبع

1. از [صفحه مخزن](https://github.com/kazemi44468-bot/karbordi) دکمه **Code → Download ZIP** را بزنید و فایل ZIP را استخراج کنید.
2. اگر Python نصب نیست، [Python 3.10 یا جدیدتر](https://www.python.org/downloads/windows/) را نصب کنید و گزینه **Add Python to PATH** را فعال کنید.
3. داخل پوشه استخراج‌شده روی فایل **install.bat** دوبار کلیک کنید. این فایل یک میان‌بر با نام **«کاربُردی - انتقال فایل»** روی دسکتاپ می‌سازد.
4. از این به بعد با دوبار کلیک روی میان‌بر دسکتاپ برنامه را اجرا کنید.

## هر بار برای انتقال فایل

1. روی رایانه‌ای که می‌خواهید میزبان باشد، میان‌بر دسکتاپ را اجرا کنید.
2. پنجره برنامه یک **کد اتصال شش‌رقمی** و آدرس‌هایی شبیه `http://192.168.1.5:8765` نشان می‌دهد.
3. گوشی یا رایانه دوم را به همان Wi-Fi وصل کنید و آدرس آن را در مرورگر دستگاه وارد کنید.
4. کد شش‌رقمی را وارد کنید.
5. برای فرستادن فایل از گوشی/رایانه دوم، بخش **«ارسال فایل به میزبان»** را به‌کار ببرید. فایل در پوشه `KarbordiFiles/Received` ذخیره می‌شود.
6. برای فرستادن فایل از رایانه میزبان به دستگاه دوم، فایل را در پوشه `KarbordiFiles/Shared` کپی کنید، در صفحه انتقال **«تازه‌سازی»** را بزنید و کنار فایل **«دریافت»** را انتخاب کنید.

## ظاهر و پوشه‌ها

صفحه انتقال، فارسی و راست‌چین است و با تم سبز و سفید طراحی شده است.

- `KarbordiFiles/Shared`: فایل‌هایی که می‌خواهید دیگر دستگاه‌ها دریافت کنند.
- `KarbordiFiles/Received`: فایل‌هایی که از دیگر دستگاه‌ها دریافت می‌کنید.

## نکات مهم

- رایانه میزبان باید روشن بماند و پنجره برنامه باز باشد؛ بستن آن انتقال را متوقف می‌کند.
- اگر Windows Firewall پرسید، فقط برای **شبکه خصوصی (Private network)** اجازه دسترسی بدهید.
- این نسخه برای شبکه محلی است و انتقال از راه دور اینترنتی ندارد.
- کد اتصال را فقط با افراد مورداعتماد به اشتراک بگذارید و از شبکه عمومی استفاده نکنید.
- برای توقف برنامه، پنجره آن را فعال کنید و `Ctrl+C` بزنید.

## اگر صفحه باز نشد

- بررسی کنید هر دو دستگاه به یک Wi-Fi وصل باشند.
- آدرس را دقیقاً همراه شماره پورت وارد کنید؛ نمونه: `http://192.168.1.5:8765`.
- اگر Windows Firewall اجازه خواست، دسترسی را برای شبکه خصوصی مجاز کنید.
- اگر پیام نصب Python دیدید، Python را نصب کنید و دوباره میان‌بر را اجرا کنید.

**توجه:** کد در مخزن GitHub قرار دارد؛ GitHub خودش فایل‌ها را منتقل نمی‌کند. برنامه باید روی یکی از رایانه‌های شما اجرا شود.
